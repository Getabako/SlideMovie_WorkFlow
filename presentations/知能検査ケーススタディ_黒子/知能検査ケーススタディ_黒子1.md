# WISC-Vとは？

## Wechsler Intelligence Scale for Children - Fifth Edition
**ウェクスラー式児童用知能検査 第5版**

- **対象年齢**：6歳0ヶ月〜16歳11ヶ月
- **所要時間**：60〜90分程度
- 世界で最も広く使われている児童用知能検査

※WISC-IVから改訂され、5つの主要指標に

<!-- 画像: WISC検査のイメージ -->

---

# WISC-Vの構成（5つの主要指標）

| 指標 | 略称 | 測定する力 |
|:---|:---:|:---|
| 言語理解 | VCI | 言葉を使った思考・理解・表現 |
| 視空間 | VSI | 視覚情報の処理・空間認知 |
| 流動性推理 | FRI | 新しい問題への推論・応用力 |
| ワーキングメモリー | WMI | 情報の一時保持・操作 |
| 処理速度 | PSI | 視覚情報処理の速さ・正確さ |

<!-- 画像: 5つの指標の図解 -->

# 言語理解指標（VCI）

## Verbal Comprehension Index

**言葉を使って考える力**

- 語彙力・言語的知識
- 言葉での説明能力
- 言語的推理力

### 日常での現れ方
- 説明がうまい／苦手
- 言葉を使った学習の得意・不得意

<!-- 画像: 言葉・会話のイメージ -->

---

# 視空間指標（VSI）

## Visual Spatial Index

**目で見た情報を処理する力**

- 視覚的な情報処理
- 空間認知能力
- 形を捉える力

### 日常での現れ方
- 図形問題の得意・不得意
- 地図が読める／迷いやすい

<!-- 画像: パズル・空間認識のイメージ -->

---

# 流動性推理指標（FRI）

## Fluid Reasoning Index

**新しい問題を解く力**

- 論理的思考
- パターン認識
- 応用力

### 日常での現れ方
- 初めての問題への対応
- 規則性を見つける力

<!-- 画像: パターン・論理のイメージ -->

# ワーキングメモリー指標（WMI）

## Working Memory Index

**情報を一時的に保持して操作する力**

- 聞いたことを覚えておく
- 頭の中で情報を処理する
- 複数の情報を同時に扱う

### 日常での現れ方
- 複数の指示を覚えられるか
- 暗算の得意・不得意

<!-- 画像: 脳内メモリーのイメージ -->

# 処理速度指標（PSI）

## Processing Speed Index

**素早く正確に処理する力**

- 視覚的な情報を速く処理
- 単純作業のスピード
- 正確性との両立

### 日常での現れ方
- テストで時間が足りない
- 書くスピードが遅い

# 結果を読む際のポイント①

## 指標間のディスクレパンシー

**ディスクレパンシー = 指標間の有意な差**

- 各指標間の差が**15ポイント以上**で有意差あり
- 強みと弱みのパターンを把握
- **全検査IQだけでは見えない**個人内差

### 例
VCI 110、VSI 80 → 言語は得意、視覚処理は苦手

# 結果を読む際のポイント②

## 検査中の行動観察

**数値だけでなく「どう取り組んだか」が重要**

- 取り組み方、反応の様子
- 集中の持続性
- 難しい課題への対処法
- 結果に影響した要因の考慮

# 結果を読む際のポイント③

## 日常生活との照合

**検査結果と生活場面の整合性を確認**

- 学校での様子
- 家庭での様子
- 本人・保護者からの聞き取り
- 先生からの情報

→ 結果と日常が一致しない場合は要検討
