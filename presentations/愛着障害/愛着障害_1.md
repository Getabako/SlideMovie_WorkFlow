# 愛着障害とは

## 定義と基本概念

### 愛着障害の本質

- 乳幼児期の養育者との関係性の問題により形成される障害
- 安全で安定した愛着関係が築けなかった結果生じる
- 対人関係、感情調節、自己認識に影響を及ぼす

---

# 愛着障害の主な特徴

| 乳幼児期（0-2歳） | 幼児期（3-5歳） |
|---|---|
| 養育者への愛着行動の欠如・混乱 | 他者への過度な警戒 |
| 泣いても慰められない | 無差別な愛着 |
| 抱かれても落ち着かない | 攻撃的行動 |
| 探索行動の制限 | 引きこもり傾向 |
| 過度な警戒心 | |
| 感情調節の困難 | |

---

# 思春期・青年期の愛着障がいの特徴

| 思春期前期（11-14歳） | 思春期後期・青年期（15-18歳） |
|---|---|
| アイデンティティの混乱・不安定さ | 慢性的な空虚感・孤独感 |
| 仲間関係での孤立・過剰適応 | 対人関係での極端な理想化と脱価値化 |
| 反抗的行動・ルール違反の増加 | 見捨てられ不安の顕著化 |
| 感情の激しい揺れ動き | |

---

# 愛着障害の種類

## 主要な分類

| タイプ | 特徴 | 行動パターン |
|---|---|---|
| 反応性愛着障害（RAD） | 情緒的引きこもり | 養育者にも愛着行動を示さない |
| 脱抑制型対人交流障害（DSED） | 境界線の曖昧さ | 見知らぬ人にも過度になれなれしい |
| 混乱型愛着 | 一貫性のない反応 | 組織化されていない愛着パターン |

---

# 愛着障害の原因

| 環境的要因 | リスク要因 |
|---|---|
| 養育者の不在・頻繁な交代 | 望まない妊娠 |
| 身体的・感情的ネグレクト | 産後うつ |
| 虐待体験 | 社会的孤立 |
| 養育者の精神的問題（うつ病、薬物依存） | 経済的困窮 |
| 長期入院・施設養育 | 養育者自身の愛着問題 |
| | 家族システムの機能不全 |

---

# 発達障害との違い

## 比較表

| 観点 | 愛着障害 | 発達障害 |
|---|---|---|
| 原因 | 環境要因が主 | 生来的な脳機能の違い |
| 症状の変化 | 関係性により変化 | 環境に関わらず一貫 |
| 改善 | 安全な環境で改善 | 特性は継続 |
| 関係性 | 特定の養育者に集中 | すべての関係で現れる |

---

# 診断と評価のポイント

## 観察すべき点

| 行動観察 | 評価ツール |
|---|---|
| 養育者との相互作用の質 | 愛着関係評価スケール |
| ストレス場面での反応 | ストレンジ・シチュエーション法 |
| 他者に対する行動パターン | 詳細な生育歴の聴取 |
| 感情調節能力 | 多職種による総合的評価 |

---

# 基本的な接し方の原則

| 安全・安心の提供 | 感情調節のサポート | 関係性の質を重視 |
|---|---|---|
| 一貫した対応を心がける | 子どもの感情を言語化して返す | 信頼関係の構築に時間をかける |
| 予測可能な環境を整える | 一緒に落ち着く方法を見つける | 子どものペースを尊重 |
| 物理的・心理的安全を確保 | | 無条件の受容を示す |

---

# 体験ワーク：愛着を感じる瞬間

## ペアワーク（5分間）

### 振り返りのテーマ

**「あなたが安心感を感じた瞬間を思い出してください」**

1. 幼少期や最近の体験から、誰かに「守られている」と感じた場面
2. 不安な時に、誰かの存在で心が落ち着いた経験
3. 失敗しても受け入れてもらえた記憶

---

# 具体的な接し方の工夫

| 日常の関わり | 困難な場面での対応 |
|---|---|
| 「大丈夫」「安全だよ」の声かけ | 感情的にならず冷静を保つ |
| 身体接触は子どものタイミングで | 行動の背景にある気持ちを理解 |
| ルーティンを大切にする | 代替行動を一緒に考える |
| 小さな成功体験を積み重ねる | 時間をかけて修復を図る |

---

# 思春期・青年期への関わり方

| 基本的な姿勢 | コミュニケーションの工夫 |
|---|---|
| 大人として対等に接する | 批判・評価を控えた傾聴 |
| 子ども扱いせず、一人の人間として尊重 | 感情の妥当性を認める |
| 意見を聞き、選択権を与える | 一緒に問題解決を考える姿勢 |

### 効果的なアプローチ

- 適切な距離感の維持
- 過度な干渉を避け、見守る姿勢
- 求められた時に支援する
