## HTMLの基本

### HTMLとは？
HyperText Markup Language
文書の構造を表す言語

### 基本構造
```html
<!DOCTYPE html>
<html>
<head>
  <title>ページタイトル</title>
</head>
<body>
  <h1>見出し</h1>
  <p>本文</p>
</body>
</html>
```
---

![bg right:45%](images/312_______________________________.png)
## よく使うHTMLタグ

| タグ | 用途 | 例 |
|------|------|-----|
| `<h1>` | 大見出し | `<h1>山田太郎</h1>` |
| `<p>` | 段落 | `<p>こんにちは</p>` |
| `<img>` | 画像 | `<img src="photo.jpg">` |
| `<a>` | リンク | `<a href="...">クリック</a>` |
| `<div>` | グループ化 | `<div>...</div>` |
---

![bg right:45%](images/313_______________________________.png)
## CSSの基本

### CSSとは？
Cascading Style Sheets
見た目を装飾する言語

### 基本構造
```css
h1 {
  color: blue;
  font-size: 32px;
}

p {
  color: gray;
  font-size: 16px;
}
```

## GitHubアカウント作成（5分）

### 手順
1. https://github.com にアクセス
2. 「Sign up」をクリック
3. メールアドレス入力
4. パスワード設定
5. ユーザー名設定（重要！）
6. 認証を完了

**既にアカウントがある方はログイン**

![bg right:45%](images/336_______________________________.png)
## リポジトリの作成（5分）

### 手順
1. 右上の「+」→「New repository」
2. Repository name: `あなたのユーザー名.github.io`
   - 例：`hanako-yamada.github.io`
3. Public を選択
4. 「Create repository」をクリック

**これで公開の準備完了！**
