# ワークフローヘルプ

## 利用可能なコマンド一覧

### スライド作成関連
| コマンド | 説明 | 実行者 |
|---------|------|--------|
| `/slide-create <テーマ>` | 新しいスライドを作成 | ClaudeCode |
| `/image-generate <プレゼン名>` | スライド用画像を生成 | **Gemini API** |
| `/image-insert <プレゼン名>` | 画像をスライドに挿入 | ClaudeCode |
| `/slide-to-image <プレゼン名>` | スライドをPNG画像に変換 | ClaudeCode |

### 動画作成関連
| コマンド | 説明 | 実行者 |
|---------|------|--------|
| `/scenario-write <プレゼン名>` | ナレーションスクリプト作成 | ClaudeCode |
| `/video-edit <プレゼン名>` | 動画を組み立てる | ClaudeCode |

### ワークフロー管理
| コマンド | 説明 |
|---------|------|
| `/workflow 全工程 <名前>` | 全工程を実行 |
| `/workflow <工程> <名前>` | 特定の工程を実行 |
| `/help-workflow` | このヘルプを表示 |

## クイックスタート

### 1. 新しいプレゼンテーションを作成

```
/slide-create AIの歴史について5枚のスライド
```

### 2. 画像を生成

```
/image-generate AIの歴史
```

### 3. 動画まで一気に作成

```
/workflow 全工程 AIの歴史
```

## トラブルシューティング

### Gemini API エラー
- `GOOGLE_AI_API_KEY` 環境変数を確認
- API制限を確認（リクエスト頻度）

### Marp変換エラー
- `npm install` で依存関係を再インストール
- Node.js バージョンを確認（v18推奨）

### 動画生成エラー
- FFmpeg がインストールされているか確認
- Remotion の依存関係を確認
