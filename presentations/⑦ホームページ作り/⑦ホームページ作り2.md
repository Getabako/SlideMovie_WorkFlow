## CSSとは？

### Webページのデザインを担当

**C**ascading **S**tyle **S**heets

```css
/* セレクタ { プロパティ: 値; } */

h1 {
  color: #333;
  font-size: 48px;
  text-align: center;
}
```

---

## CSSの書き方

### 3つの方法

**1. インラインスタイル**
```html
<h1 style="color: blue;">タイトル</h1>
```

**2. styleタグ内**
```html
<style>
  h1 { color: blue; }
</style>
![bg right:45%](images/020.png)
```

**3. 外部ファイル（推奨）**
```html
<link rel="stylesheet" href="style.css">
```

## よく使うCSSプロパティ

### 基本プロパティ

| プロパティ | 意味 | 例 |
|-----------|------|-----|
| `color` | 文字色 | `color: #333;` |
| `background` | 背景 | `background: #fff;` |
| `font-size` | 文字サイズ | `font-size: 16px;` |
| `margin` | 外側余白 | `margin: 20px;` |
| `padding` | 内側余白 | `padding: 10px;` |

## カラーパレット

### 配色のコツ

**メインカラー**（1色）
- ブランドを表す色
- 例：#667eea（青紫）

**サブカラー**（1-2色）
- メインを補助する色
- 例：#764ba2（紫）

**ベースカラー**
- 背景色：白、薄いグレー
- 文字色：濃いグレー、黒

## Flexboxでレイアウト

### 横並びを簡単に

```css
.skills-container {
  display: flex;
  justify-content: center;
  gap: 20px;
}
```

**justify-content**
- `center` : 中央揃え
- `space-between` : 均等配置
- `space-around` : 余白付き均等

## CSS Gridで作品表示

### グリッドレイアウト

```css
.works-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 30px;
}
```

3列×2行で6作品を表示！

---

![bg right:45%](images/027.png)
## レスポンシブ対応

### メディアクエリ

```css
/* スマホ用（768px以下） */
@media (max-width: 768px) {
  .works-grid {
    grid-template-columns: 1fr;
  }
}
```

画面サイズに応じてレイアウト変更！
