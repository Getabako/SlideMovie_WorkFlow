# ケース1の特殊性

## 学習障害（LD）の視点

### 他の2ケースとの違い
- 全体的な知的能力の問題ではない
- **特定の機能（書字）に限定**した困難
- 「読む」と「書く」の乖離

### LD支援の特徴
- 苦手な部分の**代替手段**を用意
- **強みを活かした**学習方法
- ICT機器の**合理的配慮**

# 支援を考える際の視点

## 大切なポイント

### 1. 検査結果＋行動観察
- 数値だけでなく取り組み方も重要

### 2. 強みを活かす
- 得意な認知スタイルで学べる環境

### 3. 情緒面への配慮
- 自己肯定感を下げない関わり

### 4. 実力発揮の条件
- 本来の力を出せる環境調整

# 保護者・教員への伝え方

## フィードバックのポイント

1. **数値の説明より「こういう場面で困る」を具体的に**
   - 「WMI66です」より「複数の指示を覚えにくいです」

2. **強みを先に伝え、活かし方を提案**
   - 「視覚的に示すと理解しやすいです」

3. **弱みは支援方法とセットで**
   - 「書くのは苦手ですが、タブレットなら大丈夫です」

# まとめ

## 本日のふりかえり

1. **WISC-Vは子どもの認知特性を知るツール**
   - 数値だけでなく行動観察も重要

2. **指標間のバランスから強み・弱みを把握**
   - ディスクレパンシーに注目

3. **同じ「強み」でも支援の方向性は異なる**
   - 個別の特性に合わせた対応

4. **情緒面・環境要因も考慮した支援を**
   - 子どもの「できる」を引き出す

# ケース1のポイント（復習）

## 学習障害（LD）の視点

### 今回のケースから学んだこと

1. **「読む」と「書く」の乖離**に注目
2. **形態認識の困難**が書字に影響
3. **メディアによる認識の違い**
   - 紙より液晶画面が読みやすい可能性
4. **ICT機器の活用**が有効な支援策
5. **注意散漫**への環境調整も必要
