## 活用例1：顧客管理シート

### 必要な項目
- 顧客ID
- 会社名
- 担当者
- メールアドレス
- 電話番号
- 最終連絡日
- ステータス
---

![bg right:45%](images/019.png)
## 顧客管理シートの作成

### Geminiへのプロンプト
```
顧客管理用のスプレッドシートを作りたいです。

必要な機能：
1. 基本情報の管理
2. 最終連絡日からの経過日数を自動計算
3. ステータス（見込み客/商談中/成約/失注）
4. 30日以上連絡していない顧客を強調表示

構成と必要な関数を提案してください。
```

## データからグラフを作る

### Geminiへの依頼

```
以下の月別売上データから、
おすすめのグラフを提案してください。

1月：500,000円
2月：550,000円
3月：600,000円
4月：580,000円
5月：650,000円

また、グラフの作り方も教えてください。
```

## 実習6：グラフ作成（10分）

### 課題
売上データからグラフを作成

### 手順
1. データを入力
2. データ範囲を選択
3. メニューから「挿入」→「グラフ」
4. グラフの種類を選択
5. タイトルや軸ラベルを設定

**実際に作ってみましょう**
---
