## GitHub Pagesとは？

### 無料のホスティングサービス

**メリット**
- ✅ 完全無料
- ✅ 独自ドメイン可能
- ✅ HTTPSで安全
- ✅ バージョン管理
- ✅ プロが使うツール

**URL例**
`https://ユーザー名.github.io`

## GitHubアカウント作成

### 手順

1. https://github.com にアクセス
2. 「Sign up」をクリック
3. メールアドレス入力
4. パスワード設定
5. ユーザー名設定（URLになる！）
6. メール認証を完了

---

![bg right:45%](images/049.png)
## リポジトリの作成

### 手順

1. 右上の「+」→「New repository」
2. Repository name: `ユーザー名.github.io`
3. ✅ Public を選択
4. 「Create repository」をクリック

**ユーザー名と同じ名前.github.io**

---

![bg right:45%](images/050.png)
## ファイルのアップロード

### 手順

1. 「uploading an existing file」クリック
2. ファイルをドラッグ&ドロップ
   - index.html
   - 画像ファイル
3. 「Commit changes」をクリック

---

![bg right:45%](images/051.png)

2. 左メニュー「Pages」
3. Source: Deploy from a branch
4. Branch: main / root
5. 「Save」

## ページの更新方法

### 修正したい時

**方法1：GitHub上で編集**
1. ファイルをクリック
2. 鉛筆アイコン（Edit）
3. 編集して「Commit」

**方法2：再アップロード**
1. ローカルで編集
2. 古いファイルを削除
3. 新しいファイルをアップロード
