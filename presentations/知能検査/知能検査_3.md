# ④ 処理速度指標（PSI）

## 何を測るか？

簡単な視覚情報を素早く正確に処理する能力

- 作業の速さ
- 注意の持続
- 視覚的走査
- 目と手の協応

---

# 処理速度指標の下位検査

### 【符号】

記号と数字の対応表を見ながら、できるだけ速く書き写す

→ 2分間でどれだけできるか

### 【記号探し】

見本の記号が右側のグループにあるかを判断

→ 2分間でどれだけできるか

**とにかくスピード勝負！**

---

# 処理速度が高い子の特徴

- 作業が速い
- テストを早く終える
- 書き写しが速い
- ゲームの反応が早い
- テキパキしている

### でも逆に...

- じっくり考えるのが苦手かも
- ケアレスミスをしやすいことも

---

# 処理速度が低いと...

## こんな困り感があるかもしれません：

- 「時間内に終わらない」
- 「黒板の書き写しが遅い」
- 「テストで時間が足りない」
- 「動作がゆっくり」

### 支援のポイント

- 時間を十分に確保
- 量を調整する
- 急かさない
- 「遅い」ではなく「丁寧」と捉える

# 5. 実践編

## 日常会話からIQを見抜く？！

---

# 実は私、やってます...

## 普段の会話の中で、なんとなくIQを目算しています

### 見ているポイント

1. 言葉の理解力 → 言語理解
2. 話の展開の仕方 → 知覚推理 or 言語理解
3. 指示の通り方 → ワーキングメモリー
4. 作業のスピード感 → 処理速度
5. 話の抽象度 → 言語理解

---

# 例えばこんな感じ...

### パターン1：語彙が豊富な子

「先生、僕は昨日、すごく困惑したんです」

→ 言語理解高そう！ 小学生で「困惑」使える！

### パターン2：説明が視覚的な子

「あのね、こう...こうやって...（ジェスチャー）」

→ 知覚推理高くて、言語理解は平均的かな？

---

# 例えばこんな感じ...（続き）

### パターン3：指示の入り方

「〇〇を取って、△△に置いて、その後□□してね」

- すぐできる → ワーキングメモリー高い
- 「え、なんだっけ？」→ ワーキングメモリー注意

### パターン4：作業の進め方

プリント配布中...

- サッと終わる子 → 処理速度高い
- 丁寧にゆっくりな子 → 処理速度は平均的

---

# 注意事項

- あくまで「目算」であり、正式な検査ではありません
- 環境や体調、興味によっても大きく変わります
- ただし、子どもの認知特性を理解するヒントにはなります

「あ、この子は言語理解高いから、言葉で説明すればわかる」

「処理速度が低めだから、時間を多めに取ろう」

**→ 関わり方を調整できる！**

---

# 認知特性に合わせた支援の例

| 特性 | 支援方法 |
|---|---|
| 言語理解が高い子 | 言葉で丁寧に説明する |
| 知覚推理が高い子 | 図や絵を使って説明する |
| ワーキングメモリーが低い子 | 指示は短く、1つずつ、メモを活用 |
| 処理速度が低い子 | 時間を十分に、量を調整 |

# 大切なのは...

## 凸凹を「個性」として捉える

- IQは「優劣」ではなく「特性」
- 誰にでも得意・不得意がある
- 「できない」ではなく「違う方法が必要」
- その子に合った方法を一緒に探す

> 「みんな違って、みんないい」
> その子の特性を理解し、尊重することが大切

# 今日学んだこと

1. 知能は多面的なもの
2. WISC-Ⅳは4つの指標で認知特性を測る

3. 日常の観察からも特性のヒントは得られる
4. 認知特性を知ることで、適切な支援ができる

- 得意を活かし、苦手を補う支援を
- 個性を尊重した関わりを心がけましょう
