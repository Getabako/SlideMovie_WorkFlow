# プレゼンテーション生成

プロンプトに基づいてプレゼンテーションのスライドを自動生成します。

## 入力パラメータ
- `$ARGUMENTS` : プレゼンテーション名とプロンプト（スペース区切り）
  - 例：「AI入門講座 AIの基礎から応用まで解説する初心者向け講座」

## 実行手順

### 1. 引数の解析
- 最初の単語をプレゼンテーション名として取得
- 残りをプロンプト（大まかな内容）として取得

### 2. フォルダ作成
`/Users/takasaki19841121/Desktop/SlideMovie_WorkFlow-main/presentations/[プレゼン名]/` フォルダを作成

### 3. スライド生成ルール

#### 3.1 ファイル分割ルール
- **1ファイルにつき最大15スライドまで**
- 15スライドを超える場合は複数ファイルに分割：
  - `[プレゼン名]1.md` （スライド1-15）
  - `[プレゼン名]2.md` （スライド16-30）
  - `[プレゼン名]3.md` （スライド31-45）
  - 以降同様

#### 3.2 Marpスライド形式
各.mdファイルは以下の形式で作成：

```markdown
---
marp: true
theme: default
paginate: true
---

# スライドタイトル

内容

---

# 次のスライド

内容

---
```

#### 3.3 スライド構成の目安
1. **タイトルスライド** - プレゼン名、講師名（塾頭高崎翔太）
2. **目次スライド** - 全体の流れ
3. **導入** - なぜこのテーマが重要か
4. **本編** - 主要コンテンツ（複数スライド）
5. **まとめ** - 要点の整理
6. **次回予告/質問受付** - クロージング

#### 3.4 スライド内容のガイドライン
- 1スライド1メッセージを心がける
- 箇条書きは5項目以内
- 専門用語は初出時に説明
- 具体例やイラスト指示を含める
- 講師が説明する際の台本（ノート）も考慮

### 4. 画像配置用のプレースホルダー
各スライドに画像を入れる場所として、以下のコメントを入れておく：
```markdown
<!-- 画像: [画像の説明] -->
```

## 出力
- `presentations/[プレゼン名]/[プレゼン名]1.md`
- `presentations/[プレゼン名]/[プレゼン名]2.md` （必要に応じて）
- 以降、15スライドごとに分割

## 注意事項
- プロンプトに基づいてスライド数を適切に決定
- 短い講座は15スライド以内、長い講座は30-60スライド程度
- 各ファイルは独立して完結するよう、適切な区切りで分割
