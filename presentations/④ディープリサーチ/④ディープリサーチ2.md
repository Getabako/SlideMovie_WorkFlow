# 第4部：情報の信頼性チェック（15分）
---

![bg right:45%](images/177_______________________________.png)
## AIの回答を鵜呑みにしない

### 確認が必要な理由
- AIは間違うことがある（ハルシネーション）
- 情報が古い可能性
- 地域差がある情報
- 法律・制度の変更
---

![bg right:45%](images/178_______________________________.png)
## 情報の信頼性を確認する方法

### 1. 複数の質問で裏取り
```
先ほどの回答について、情報源や
根拠となるデータを教えてください。
```

### 2. 具体的な数字を確認
```
○○の数字について、どの調査や
統計に基づいていますか？
```
---

![bg right:45%](images/179_______________________________.png)
## クロスチェックの方法

### Geminiで確認
```
「Web制作の平均年収が400万円」という情報は
正確ですか？最新のデータに基づいていますか？
```

### 公式サイトで確認
- 政府の統計サイト
- 業界団体の公式サイト
- 企業の公式ページ
