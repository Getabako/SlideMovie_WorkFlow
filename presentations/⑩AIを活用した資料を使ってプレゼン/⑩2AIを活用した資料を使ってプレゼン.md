# 第1部：プレゼン資料作成（55分）

---

## 今日のミッション

### 作るもの
**5分間のプレゼンテーション**

### テーマ（3つから選択）
1. 「私が提案する業務改善アイデア」
2. 「AIを活用した○○サービス企画」
3. 「未来の働き方とIT活用」

### 使うツール
- Gemini：企画・構成・文章
- Googleスライド：資料作成
- AI画像生成：ビジュアル（オプション）

---

## ステップ1：テーマ選定（5分）

### 決めること
1. テーマを選ぶ
2. 誰に向けて話すか
3. 何を伝えたいか
4. どう行動してほしいか

### 簡単なメモ
```
テーマ：
対象：
メッセージ：
ゴール：
```

---

## ステップ2：構成作成（10分）

### Geminiに依頼

```
以下のテーマで5分間のプレゼンテーションを
作りたいです。構成案を提案してください。

【テーマ】[あなたのテーマ]
【対象】[対象者]
【目的】[目的]
【メッセージ】[伝えたいこと]

構成：
- スライド枚数（7-10枚程度）
- 各スライドのタイトルと内容
- 時間配分
```

---

## ステップ3：スライド内容作成（15分）

### 各スライドをGeminiで作成

```
【スライド1：タイトル】
魅力的なタイトルとサブタイトルを
提案してください。

【スライド2：現状分析】
現状の課題を3つの箇条書きで。
データや数字も含めて。

【スライド3：提案内容】
...
```

**効率的に進めましょう**

---

## ステップ4：スライド作成（15分）

1. 新規スライド作成

5. 画像追加（必要に応じて）

### 時短のコツ
- テンプレート活用
- コピー&ペースト
- シンプルに

## ステップ5：ブラッシュアップ（10分）

## プレゼンターノートとは？

**スライドごとに話す内容をメモする機能**

### メリット
- 話す内容を忘れない
- 時間配分を意識
- 落ち着いて話せる
- 練習がしやすい

---

## Geminiでノート作成

### プロンプト例

```
以下の各スライドについて、
プレゼンターノート（話す内容）を
作成してください。

各スライドは30-60秒で話せる内容で。
自然な話し言葉で。

【スライド1】
[内容]

【スライド2】
[内容]

...
```
