# 良いプロンプトの書き方

## 基本構成

```
【何を作るか】
○○するWebアプリを作ってください。

【機能・条件】
- 機能1
- 機能2
- 機能3

【技術的な指定】
- HTML/CSS/JavaScriptで
- 1ファイルで完結
- レスポンシブ対応
```

# プロンプトのコツ①：具体的に

## 悪い例

```

```

## 良い例

```
Todoリストアプリを作ってください。
- ダークモードのデザイン
- 角丸のカード型UI
- アニメーション付きの追加・削除
```

**「かっこいい」を具体的な要素に分解する**

# プロンプトのコツ③：制約を伝える

## 技術的な制約

```
【重要な制約】
- 1つのHTMLファイルで完結させてください
- 外部ライブラリは使わないでください
- サーバーは使わず、ブラウザだけで動くようにしてください
```

## なぜ重要？

- GitHub Pagesで動かすため
- シンプルに保つため
- 依存関係のトラブルを避けるため

# エラーが出た時の対処法

## バイブコーディングの必須スキル

1. **開発者ツールでエラーを確認**
2. **エラーメッセージをコピー**
3. **AIに共有して解決策を聞く**

**これができれば怖いものなし！**

# 開発者ツールを開く

## ブラウザの開発者ツール

### 開き方

- **Windows**: `F12` または `Ctrl + Shift + I`
- **Mac**: `Cmd + Option + I`
- または右クリック →「検証」

### 確認するタブ

- **Console** ← エラーメッセージが表示される

---

# エラーの読み方

## Consoleタブの見方

```
Uncaught TypeError: Cannot read property 'value' of null
    at script.js:15
```

### 読み解き方

- **エラーの種類**: TypeError
- **内容**: nullのvalueを読もうとした
- **場所**: script.js の 15行目

---

# エラーをAIに共有する

## プロンプト例

```
以下のエラーが出ています。原因と解決方法を教えてください。

【エラーメッセージ】
Uncaught TypeError: Cannot read property 'value' of null
    at script.js:15

【該当するコード】
const input = document.getElementById('userInput');
const value = input.value;
```

**エラーメッセージ + 関連コードをセットで共有**

# 開発の進め方まとめ

## バイブコーディングの流れ

1. **AIに基本機能を作ってもらう**
2. **動作確認する**
3. **エラーがあれば開発者ツールで確認**
4. **エラーをAIに共有して修正**
5. **追加機能を依頼**
6. **繰り返し**

**さあ、開発を始めよう！**
