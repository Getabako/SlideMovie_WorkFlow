====How to install(Windows)===========================================

1. Insert the installation disk into the drive.

2. Find "AHS_Launcher.exe" and click it.

3. The product launcher comes up.
   On the launcher, click, "Install the main program".

4. Follow the instructions on the screen to start downloading the 
installer.
Enter your activation code when downloading.

5. When the installer download is complete, run the downloaded 
installer.

6. Follow the instructions in the installer to complete the 
installation.

The installation is now complete.

More detailed install guide is also enclosed in the package.


====How to install(macOS)=============================================

1. Insert the installation disk into the drive.

2. Find "voicepeak-downloader.zip" on the disk and click it.
(For the downloadable version, click "voicepeak-downloader.zip" as well.)

3. Follow the instructions on the screen to start downloading the installer.
Enter your activation code when downloading.

4. When the installer download is complete, run the downloaded installer.
