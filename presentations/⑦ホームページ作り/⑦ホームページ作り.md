## HTMLとは？

## CSSとは？

### Webページのデザインを担当

**C**ascading **S**tyle **S**heets

```css
/* セレクタ { プロパティ: 値; } */

h1 {
  color: #333;
  font-size: 48px;
  text-align: center;
}
```

---

## CSSの書き方

### 3つの方法

**1. インラインスタイル**
```html
<h1 style="color: blue;">タイトル</h1>
```

**2. styleタグ内**
```html
<style>
  h1 { color: blue; }
</style>
![bg right:45%](images/020.png)
```

**3. 外部ファイル（推奨）**
```html
<link rel="stylesheet" href="style.css">
```

| `margin` | 外側余白 | `margin: 20px;` |

### スクロール検知の仕組み
