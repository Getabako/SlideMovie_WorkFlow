# Geminiで作る！はじめてのゲーム開発
## Part2: ゲーム開発編（約25分）

---

# ゲームファイルを作ろう

## 手順

1. 「mygame」フォルダを開く
2. 右クリック →「新規作成」→「テキストドキュメント」
3. ファイル名を「**index.html**」に変更
   - 「.txt」は消して「.html」にする
   - 警告が出たら「はい」をクリック

---

# フォルダ構造の確認

```
デスクトップ/
  └── mygame/
       ├── index.html  ← 今作ったファイル
       └── images/
            └── player.png
```

---

# Geminiにコードを作ってもらおう

## プロンプト（コピーして使ってね）

```
HTMLとJavaScriptで簡単なゲームを作ってください。

【条件】
- 1つのHTMLファイルで完結する
- キャラクター画像は images/player.png を使う
- 矢印キーの左右でキャラクターが移動する
- スペースキーでジャンプする
- 画面右端にゴールを置く
- ゴールに触れたら「クリア！」と表示
- 画面サイズは800x400ピクセル
- 地面があり、キャラクターは地面の上を歩く
```

---

# コードをコピーしよう

## 手順

1. Geminiが作ったコードを確認
2. コード全体を選択してコピー
   - Ctrl+A（全選択）→ Ctrl+C（コピー）
   - または「コードをコピー」ボタンをクリック

---

# コードを貼り付けよう

## 手順

1. 「index.html」を右クリック
2. 「プログラムから開く」→「メモ帳」を選択
3. 中身を全部消す
4. コピーしたコードを貼り付け（Ctrl+V）
5. 保存する（Ctrl+S）

---

# ゲームを起動しよう！

## 手順

1. 「index.html」をダブルクリック
   - または右クリック →「プログラムから開く」→ ブラウザを選択
2. ブラウザでゲームが表示される

---

# 動かしてみよう

## 操作方法

- **← キー**：左に移動
- **→ キー**：右に移動
- **スペースキー**：ジャンプ

**ゴールを目指してみよう！**

---

# うまく動かない場合（1/2）

## キャラクターが表示されない

- 画像ファイル名が「player.png」か確認
- imagesフォルダに入っているか確認
- フォルダ名が「images」か確認（大文字小文字も注意）

---

# うまく動かない場合（2/2）

## ゲーム画面が真っ白・動かない

- ファイル名が「index.html」か確認
- 「.html」で終わっているか確認
- コードを最初からコピーし直してみる
