# Geminiで作る！はじめてのゲーム開発
## Part1: 準備・画像作成編（約20分）

---

# 今日作るゲーム

- AIで自分だけのキャラクターを作る
- キャラクターを左右に動かせる
- ジャンプもできる
- ゴールを目指すシンプルなゲーム

**60分で完成を目指そう！**

---

# 必要なもの

- パソコン（Windows / Mac）
- インターネット接続
- Googleアカウント（Gemini用）
- テキストエディタ（メモ帳でOK）

---

# 作業フォルダを作ろう（1/3）

## 手順

1. **デスクトップ**を開く
2. 右クリック → 「新規作成」→「フォルダ」
3. フォルダ名を「**mygame**」にする

---

# 作業フォルダを作ろう（2/3）

## 手順

4. 作った「mygame」フォルダを開く
5. 中で右クリック →「新規作成」→「フォルダ」
6. フォルダ名を「**images**」にする

---

# 作業フォルダを作ろう（3/3）

## 完成したフォルダ構造

```
デスクトップ/
  └── mygame/
       └── images/    ← 画像を入れる場所
```

**この構造ができたら準備OK！**

---

# Geminiを開こう

## 手順

1. ブラウザで **gemini.google.com** にアクセス
2. Googleアカウントでログイン
3. チャット画面が出たら準備完了

---

# Geminiでキャラクター画像を作ろう

## やること

AIに「こんなキャラクターを描いて」とお願いする

**ポイント：**
- どんな見た目か具体的に伝える
- ゲーム用なので背景は透明か単色が良い
- 正面を向いているとゲームで使いやすい

---

# プロンプト（AIへの指示）

## コピーして使ってね

```
ゲーム用のキャラクター画像を作ってください。

- かわいいロボットのキャラクター
- 正面を向いている
- 全身が見える
- 背景は白一色
- シンプルなデザイン
```

---

# 自分だけのキャラクターにするなら

## アレンジ例

```
ゲーム用のキャラクター画像を作ってください。

- 青い忍者のキャラクター
- 正面を向いている
- 全身が見える
- 背景は白一色
- シンプルなデザイン
```

**「ロボット」を好きなものに変えてみよう！**
例：ネコ、宇宙人、騎士、魔法使い など

---

# 画像をダウンロードしよう（1/2）

## 手順

1. Geminiが作った画像を確認
2. 気に入らなければ「もう一度作って」と言う
3. 気に入ったら画像をクリック

---

# 画像をダウンロードしよう（2/2）

## 手順

4. 右下の「ダウンロード」ボタンをクリック
5. ダウンロードフォルダに保存される

---

# 画像を移動しよう

## 手順

1. ダウンロードした画像を見つける
2. ファイル名を「**player.png**」に変更
3. 画像を「**mygame/images**」フォルダに移動

---

# 確認しよう

## フォルダ構造

```
デスクトップ/
  └── mygame/
       └── images/
            └── player.png  ← ここに画像がある！
```

**これでPart1完了！**

---
