# 支援策②：ICT機器の活用

## タブレットを学習に取り入れる

### 認識しやすいデジタル環境
- 高コントラストで文字がくっきり
- フォントサイズ調整可能

### タブレット学習のメリット
- 本人の**強み**を活かせる
- 自己肯定感を下げない
- 学習への意欲を維持

# 支援策③：注意・集中への対応

## 環境調整

### 刺激のコントロール
- テレビは消す（学習時）
- 視界に入る物を減らす
- 静かな環境を用意

### 作業環境の工夫
- 机の上は必要最小限に
- 仕切りやパーテーションの活用
- 気が散りにくい座席位置

# 支援策③：集中を維持する工夫

## 時間管理と休憩

### 短い集中時間を積み重ねる
- 15分作業 → 5分休憩
- タイマーを活用
- 「ここまでやったら休憩」を明確に

### 見通しを持たせる
- 今日やることを最初に確認
- 終わりの時間を伝える
- 達成感を味わえる量に設定
