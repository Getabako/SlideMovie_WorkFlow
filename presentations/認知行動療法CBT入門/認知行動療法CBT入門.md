# 認知行動療法（CBT）とは？

**「考え方」と「行動」に働きかける心理療法**

- 1960年代にアーロン・ベック（精神科医）が開発
- うつ病・不安障害に対する効果が科学的に実証済み
- 薬物療法と同等かそれ以上の効果が多数報告
- 世界保健機関（WHO）も推奨する心理療法
- 短期間（12〜16回）で効果が出やすい
- 再発予防効果が高い（自分でセルフケアできるようになる）

**ポイント：出来事そのものではなく「受け取り方（認知）」に注目する**

---

# CBTの基本モデル：5つの要素

出来事 → **認知（考え）** → 感情 → 行動 → 身体反応

この5つは互いに影響し合っている

**例：友人にLINEを送ったが返信がない**

- 認知：「嫌われた」
- 感情：悲しい、不安（80%）
- 行動：もう連絡しない、SNSを何度も確認
- 身体：胸が締め付けられる、眠れない

**認知を変えると、感情・行動・身体すべてが変わる**

---

# 「認知」とは？ — 自動思考の正体

**自動思考＝出来事に対して瞬間的に浮かぶ考え**

- 0.1秒で自動的に浮かぶ（意識していない）
- 本人は「事実」だと思い込んでいる
- 過去の経験から形成されたパターン
- 気分が落ちている時ほど強くなる

**自動思考の例**
「どうせ自分なんてダメだ」
「きっとうまくいかない」
「みんな私のことを嫌っている」
「失敗したら終わりだ」

**大事なのは：これは「事実」ではなく「解釈」だということ**

# 認知の歪み10パターン①（前半5つ）

**1. 全か無か思考** — 白黒つけたがる
「100点でなければ0点と同じ」

**2. 過度の一般化** — 一度の経験で全てを判断
「いつも失敗する」（実際は1回だけ）

**3. 心のフィルター** — 悪いことだけピックアップ
10個褒められても、1個の批判だけ気になる

**4. マイナス化思考** — 良い出来事を打ち消す
「うまくいったのはたまたま」「お世辞だ」

**5. 結論の飛躍** — 根拠なく悪い結論を出す
心の読みすぎ：「あの人は私を嫌っている」
先読みの誤り：「きっと失敗する」

---

# 認知の歪み10パターン②（後半5つ）

**6. 拡大解釈と過小評価** — 失敗は大きく、成功は小さく
自分のミスは大事件、他人の成功は「普通のこと」

**7. 感情的決めつけ** — 感情を根拠にする
「不安だから、きっと危険だ」（不安＝事実ではない）

**8. すべき思考** — 自分や他人にルールを押しつける
「〜すべき」「〜でなければならない」

**9. レッテル貼り** — 自分にラベルを貼る
「自分はダメ人間だ」（1つのミスで全人格を否定）

**10. 個人化** — 全部自分のせいにする
「チームが負けたのは自分のせいだ」

**誰にでもある。気づくことが第一歩。**

# 思考記録表（コラム法）とは？

**自動思考を書き出して客観視するためのツール**

CBTの中核技法で、臨床でも広く使われている

| コラム | 内容 |
|--------|------|
| ① 状況 | いつ・どこで・何があった？ |
| ② 気分 | どんな気持ち？（0〜100%） |
| ③ 自動思考 | 頭に浮かんだ考えは？ |
| ④ 根拠と反証 | その考えの証拠は？反対の証拠は？ |
| ⑤ 適応的思考 | バランスの取れた考え方は？ |

**書くだけで気持ちが楽になる**
（研究でも、書く行為自体に感情調整効果が確認されている）

---

# コラム法の実例

**状況：** 会議で発言したら、数秒間シーンとなった

**気分：** 恥ずかしい（80%）、不安（70%）

**自動思考：**「変なこと言ってしまった。みんな呆れている」

**根拠：** 誰もすぐに反応しなかった
**反証：** その後、上司が「いい視点だね」と言った。他の人もメモを取っていた。

**適応的思考：**「沈黙は考えてくれていたのかもしれない。少なくとも上司は評価してくれた」

**気分の変化：** 恥ずかしい（80%→30%）、不安（70%→20%）

---

# 認知再構成の5つの質問

自動思考を見直す時に使える質問リスト

**① 「その考えの根拠は何？」**
→ 事実と解釈を分ける

**② 「反対の証拠はない？」**
→ 見落としている情報に気づく

**③ 「親友が同じことを言ったら、何と声をかける？」**
→ 自分に厳しすぎることに気づく

**④ 「1年後、このことを覚えている？」**
→ 物事の重大さを適切に評価する

**⑤ 「最悪・最良・現実的にはどうなる？」**
→ 極端な予測を修正する

# 行動から変える：行動活性化

**気分が先ではなく、行動が先**

うつのスパイラル：
気分が落ちる → 活動が減る → さらに気分が落ちる

行動活性化のスパイラル：
小さな行動 → 小さな達成感 → 気分が少し上がる → 次の行動

**始め方のコツ**
- 「やりたいこと」ではなく「できること」から
- ハードルは極限まで下げる（散歩5分でOK）
- 行動の前後で気分を数値化する（変化を実感する）

---

# 行動実験：考えが正しいか試してみる

**自動思考を「仮説」として検証する**

**自動思考：**「自分から誘ったら迷惑がられる」

**実験：** 実際に友人をランチに誘ってみる

**予測：** 断られる。嫌な顔をされる。

**結果：** 「いいね！」と快諾された

**学び：** 自分の予測は事実ではなかった。避けていたのは自分の方だった。

→ 頭で考えるだけでなく、行動で確かめることが最も強力な認知変容

# CBTが効果的な場面

**科学的にエビデンスが確認されている領域**

- うつ病（軽度〜中等度）

- 強迫性障害（OCD）
- PTSD
- 不眠症
- 摂食障害
- 慢性疼痛

**日常的なストレス管理にも有効**
- 仕事のプレッシャー
- 人間関係の悩み
- 子育てのイライラ
- 完璧主義の緩和

# 日常生活でのセルフCBT

**毎日少しずつ、自分の思考に気づく習慣を**

**朝：** 今日の気分を10段階でチェック（数値化の習慣）

**日中：**「あ、今自動思考が出たな」と気づく
→ 気づくだけでOK。無理に変えなくていい

**夜：** 思考記録を1つだけ書いてみる（5分でできる）

**続けるコツ**
- 完璧にやろうとしない（すべき思考に注意！）
- 気づくだけでも十分な一歩
- 自分を責めるツールにしない
- 辛い時は迷わず専門家に相談する
