# NanoBanana Proとは？

## Gemini 2.5 Flash Image（通称：NanoBanana Pro）

Google Geminiに搭載された最新の画像生成AI

### 大きな進化ポイント

| 従来の課題 | NanoBanana Pro での改善 |
|---|---|
| 文字が崩れる | 日本語テキストも綺麗に描画 |
| 一貫性がない | 同じキャラを繰り返し生成可能 |
| 指示が通りにくい | より正確な指示理解 |

---

# NanoBanana Proの使い方

## Geminiで画像生成モードにする

```
画像を生成してください：
[作りたい画像の説明]
```

または

```
以下の内容でイラストを作成してください：
[詳細な指示]
```

**Geminiが自動的に画像生成モードになります**

---

# 画像生成プロンプトの基本

## 含めるべき要素

| 要素 | 説明 | 例 |
|---|---|---|
| 主題 | 何を描くか | 「女性ビジネスパーソン」 |
| スタイル | 画風 | 「水彩画風」「写真風」 |
| 背景 | 場所や環境 | 「オフィスの会議室」 |
| 雰囲気 | 印象 | 「明るく前向きな」 |
| 構図 | 配置 | 「中央に配置」 |

# Canvaとは？

## 誰でも簡単にデザインできるツール

### 特徴

- 無料で使える（有料版もあり）
- テンプレートが豊富
- ドラッグ＆ドロップで編集
- AI機能が充実

# CanvaでのAI活用

## 使えるAI機能

| 機能 | できること |
|---|---|
| Magic Design | キーワードからデザイン自動生成 |
| 背景除去 | ワンクリックで背景削除 |

| テキスト生成 | キャッチコピー自動作成 |
