# AIとは？

## Artificial Intelligence（人工知能）

人間の知的な活動をコンピュータで再現する技術

- **学習する** - データから規則性を見つける
- **理解する** - 言葉や画像の意味を把握
- **判断する** - 状況に応じた対応を選択
- **創造する** - 新しい文章や画像を生成

# プロンプトとは？

## AIに対する質問や指示のこと

**プロンプトの質 = AIの回答の質**

良いプロンプトを書けば、良い結果が得られる！

---

# 悪いプロンプトの例

### 悪い例

```
メールを書いて
```

### 何が足りない？

- 誰に送るメール？
- どんな内容？
- どんな雰囲気？
- 文字数は？

**AIが「何を求められているか」わからない**

---

# 良いプロンプトの例

### 良い例

```
取引先の田中様に、明日の会議の時間を
14時から15時に変更してもらうお願いのメールを、
丁寧な文章で200字程度で書いてください。
```

### なぜ良い？

- 相手が明確（取引先の田中様）
- 目的が明確（時間変更のお願い）
- トーンが指定（丁寧な文章）
- 分量が指定（200字程度）

---

# プロンプトの5つの要素

良いプロンプトには以下の要素を含める：

| 要素 | 説明 | 例 |
|---|---|---|
| 役割 | AIに演じてほしい立場 | 「あなたはビジネスメールの専門家です」 |
| 背景 | 状況や文脈 | 「新製品の発表会を控えています」 |
| 指示 | 具体的にやってほしいこと | 「案内メールを作成してください」 |
| 条件 | 制約や形式 | 「200字以内で」 |
| 出力形式 | 回答の形 | 「箇条書きで」 |
