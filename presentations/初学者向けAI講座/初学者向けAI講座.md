# プロンプトとは？

**AIに対する質問や指示のこと**

プロンプトの質 = AIの回答の質

**良いプロンプトを書けば、良い結果が得られる！**

---

![bg right:45%](images/012.png)
# 悪いプロンプトの例

## ❌ 悪い例
```
メールを書いて
```

### 何が足りない？
- **誰に**送るメール？
- **どんな内容**？
- **どんな雰囲気**？
- **文字数**は？

AIが「何を求められているか」わからない

---

![bg right:45%](images/013.png)
# 良いプロンプトの例

## ✅ 良い例
```
取引先の田中様に、明日の会議の時間を
14時から15時に変更してもらうお願いのメールを、
丁寧な文章で200字程度で書いてください。
```

### なぜ良い？
- **相手**が明確（取引先の田中様）
- **目的**が明確（時間変更のお願い）
- **トーン**が指定（丁寧な文章）
- **分量**が指定（200字程度）

---

![bg right:45%](images/014.png)
# プロンプトの5つの要素

良いプロンプトには以下の要素を含める：

| 要素 | 説明 | 例 |
|------|------|-----|
| **役割** | AIに演じてほしい立場 | 「あなたはビジネスメールの専門家です」 |
| **背景** | 状況や文脈 | 「新製品の発表会を控えています」 |
| **指示** | 具体的にやってほしいこと | 「案内メールを作成してください」 |
| **条件** | 制約や形式 | 「300字以内、丁寧な口調で」 |
| **出力形式** | 結果の形 | 「箇条書きで」「表形式で」 |

# AIを使う際の注意点

## ❌ やってはいけないこと
- 機密情報を入力する
- 個人情報を入力する
- AIの回答を100%鵜呑みにする

## ✅ 心がけること
- 回答の内容を必ず確認する
- 重要な情報は元ソースを確認
- AIは「アシスタント」として活用

---

![bg right:45%](images/040.png)
# AIの限界を知る

## ハルシネーション（幻覚）
- 事実でない情報を自信満々に回答することがある
- 特に数字や固有名詞に注意

## 対策
- 複数の情報源で確認
- 「出典を教えて」と聞く
- 最新情報は別途確認

**AIは便利だが、最終判断は人間が行う**
