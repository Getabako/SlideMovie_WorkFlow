# 思春期・青年期支援の注意事項

| 避けるべき対応 | リスク管理 |
|---|---|
| 権威的・支配的な態度 | 自傷・他害のリスク評価 |
| 感情的な叱責・批判 | 危機介入プロトコルの準備 |
| プライバシーの侵害 | 医療機関との連携体制 |
| 他者との比較 | 家族への情報共有の判断 |

**絶対に避けること・緊急時の対応を事前に準備**

# ケーススタディ

| 事例1: 5歳男児Aさん | 事例2: 8歳女児Bさん |
|---|---|
| **症状**: 他者への過度な警戒、感情調節困難 | **症状**: 無差別な愛着行動、衝動性 |
| **背景**: 乳児期の長期入院、養育者の頻繁な交代 | **背景**: ネグレクト体験、複数の養育環境の変化 |
| **支援**: 安定した関係性の提供、感情調節スキルの習得 | **支援**: 境界線の理解、安全な関係性の学習 |

# 思春期のケーススタディ

| 事例3: 14歳男子Cさん | 事例4: 16歳女子Dさん |
|---|---|
| **症状**: 激しい感情の揺れ、自傷行為、不登校 | **症状**: 見捨てられ不安、リストカット、摂食障害 |
| **背景**: 幼少期の虐待、里親家庭での生活 | **背景**: 親の離婚、母親のうつ病、感情的ネグレクト |
| **経過**: 小学校までは過剰適応、中学で問題行動顕在化 | **経過**: 対人関係の不安定さ、SNSでのトラブル |

**支援アプローチ：個別の背景を理解した上での継続的支援**

# まとめと今後の課題

| 重要なポイント | 今後の課題 |
|---|---|
| 愛着障害は関係性の障害 | 早期発見・早期介入システムの充実 |
| 環境要因が主たる原因 | 専門職の養成と連携強化 |
| 適切な支援により改善可能 | 家族支援体制の整備 |
| 長期的・継続的な支援が必要 | 社会的理解の促進 |

**一人ひとりの子どもの可能性を信じて**
