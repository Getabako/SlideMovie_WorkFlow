# 作れるアプリの種類

## 難易度別に紹介

| レベル | 内容 | 目安時間 |
|--------|------|----------|
| 初級 | 静的サイト・ポートフォリオ | 1-2時間 |
| 中級 | インタラクティブなアプリ | 2-4時間 |
| 上級 | AI機能を組み込んだアプリ | 4-6時間 |

**自分のレベルに合わせて選ぼう！**

# 初級①：自己紹介サイト

## こんなアプリ

- 自分のプロフィールを載せるページ
- 写真、経歴、趣味などを紹介
- シンプルなデザイン

## プロンプト例

```
自己紹介用のWebページを作ってください。
名前、写真、自己紹介文、趣味、連絡先を
載せられるシンプルなデザインでお願いします。
```

# 中級①：Todoアプリ

## こんなアプリ

- タスクの追加・削除・完了管理
- データはブラウザに保存される

## プロンプト例

```
Todoリストアプリを作ってください。
- タスクの追加、削除、完了切り替えができる
- localStorageでデータを保存
- シンプルでモダンなデザイン
- レスポンシブ対応
```

# 中級②：クイズアプリ

## こんなアプリ

- 複数の問題に回答していく
- 正解数をカウントして結果表示

## プロンプト例

```
4択クイズアプリを作ってください。
- 10問の問題を出題
- 正解・不正解をその場で表示
- 最後に正解数と正答率を表示
- 問題データは配列で管理
テーマは「日本の都道府県」でお願いします。
```

# 上級アプリはAntigravityで作ろう

## AI機能を使うアプリの開発環境

**Antigravity（antigravity.build）の特徴**

- AI APIの連携が簡単
- 面倒な設定なしでAI機能が使える
- 作ったアプリをワンクリックで公開
- コードの自動生成・修正機能付き

**上級アプリに挑戦する人はAntigravityを使おう！**

# 作るアプリを決めよう

## 決める時のポイント

1. **今日中に完成できるか**
   - 欲張りすぎない、シンプルに始める
2. **自分が使いたいか**
   - モチベーションが続く
3. **説明できるか**
   - AIに伝えられるイメージがある

**決まったら次へ進もう！**
