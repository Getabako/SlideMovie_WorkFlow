# GitHubとは？

## 世界最大のコード共有プラットフォーム

- コードを保存・管理できる
- バージョン管理（履歴が残る）
- 他の人と共同開発できる
- **無料でWebサイトを公開できる**

**エンジニアの必須ツール！**

---

# なぜGitHubを使うのか

## 今日のメリット

1. **作ったアプリを公開できる**
   - GitHub Pagesで世界中からアクセス可能
2. **コードが消えない**
   - クラウドに保存されるので安心
3. **ポートフォリオになる**
   - 就活でアピールできる

# GitHubアカウント作成（1/3）

## 手順

1. **github.com** にアクセス
2. 「Sign up」をクリック
3. メールアドレスを入力
4. パスワードを設定（15文字以上推奨）
5. ユーザー名を決める

---

# GitHubアカウント作成（2/3）

## ユーザー名のポイント

- **本名または覚えやすい名前**
- 就活で見られる可能性あり
- 後から変更も可能

## 例

- yamada-taro
- taro2024
- tarodev

# リポジトリを作成（1/3）

## リポジトリとは？

- コードを保存する「フォルダ」のようなもの
- 1つのプロジェクト = 1つのリポジトリ

## 手順

1. 右上の「+」→「New repository」をクリック

---

# リポジトリを作成（2/3）

## 設定項目

| 項目 | 設定 |
|------|------|
| Repository name | アプリ名（英語、ハイフン可） |
| Description | アプリの説明（任意） |
| Public/Private | **Public**（公開する場合） |
| Add a README | **チェックを入れる** |

---

# リポジトリを作成（3/3）

## リポジトリ名の例

- my-first-app
- todo-app
- portfolio-site
- quiz-game

**「Create repository」をクリック！**

---

# ファイルを追加する（1/2）

## 手順

1. 「Add file」→「Create new file」をクリック
2. ファイル名に「**index.html**」と入力
3. 下のテキストエリアにコードを貼り付け

---

# ファイルを追加する（2/2）

## コミット（保存）する

1. 画面下の「Commit changes」エリアへ
2. コミットメッセージを入力
   - 例：「最初のコードを追加」
3. 「Commit changes」ボタンをクリック

**これでファイルがGitHubに保存された！**

---

# GitHub Pagesで公開（1/3）

## GitHub Pagesとは？

- GitHubのリポジトリをWebサイトとして公開
- 無料で使える
- URLは `ユーザー名.github.io/リポジトリ名`

---

# GitHub Pagesで公開（2/3）

## 設定手順

1. リポジトリページで「Settings」タブをクリック
2. 左メニューの「Pages」をクリック
3. 「Source」で「Deploy from a branch」を選択
4. 「Branch」で「main」を選択
5. フォルダは「/ (root)」のまま
6. 「Save」をクリック

---

# GitHub Pagesで公開（3/3）

## 公開URLを確認

1. 数分待つ（デプロイ処理中）
2. Pagesの設定画面をリロード
3. 上部に公開URLが表示される

```
https://あなたのユーザー名.github.io/リポジトリ名/
```

**おめでとう！世界に公開された！**

---

# ファイルの更新方法

## コードを修正したい場合

1. GitHubでファイルをクリック
2. 右上の鉛筆アイコン（Edit）をクリック
3. コードを編集
4. 「Commit changes」で保存

**保存後、数分でサイトに反映される**
