# WISC-Vの基礎知識

## WISC-Vの構成（5つの主要指標）

- **言語理解 (VCI)**: 言葉を使った思考・理解・表現
- **視空間 (VSI)**: 視覚情報の処理・空間認知
- **流動性推理 (FRI)**: 新しい問題への推論・応用力
- **ワーキングメモリー (WMI)**: 情報の一時保持・操作
- **処理速度 (PSI)**: 視覚情報処理の速さ・正確さ

---

# 指標得点の解釈

## 得点の目安

| 得点範囲 | 分類記述 |
|---|---|
| 130以上 | 極めて高い |
| 120-129 | 非常に高い |
| 110-119 | 平均の上 |
| 90-109 | 平均 |
| 80-89 | 平均の下 |
| 70-79 | 非常に低い |
| 69以下 | 極めて低い |

---

# 結果を読む際のポイント

## 注目すべき点

### 1. 指標間のディスクレパンシー

- 指標間の有意差を確認
- 強みと弱みのパターンを把握

### 2. 検査中の行動観察

- 取り組み方、反応の様子
- 結果に影響した要因の考慮

### 3. 日常生活との照合

- 学校・家庭での様子との整合性

# ケース1：Aさん（15歳・中学3年生）

## 検査結果

- **全検査IQ**: 54（極めて低い）
- **言語理解**: 58
- **視空間**: 63
- **流動性推理**: 58
- **ワーキングメモリー**: 71
- **処理速度**: 45

---

# Aさんの検査中の様子

## 行動観察

- 導入はスムーズ、あいさつして入室
- 質問には小声でボソッと答える
- 反応や動作はゆっくりで慎重
- 難しい時は「わかりません」と言える
- 姿勢の崩れなく集中持続
- ミスはなく、一つ一つ丁寧に取り組む

# Aさんの特性解説

## 認知特性の理解

### 相対的な強み

- ワーキングメモリーが71と他指標より高い
- 情報を一時的に保持する力は比較的保たれている

### 弱み

- 処理速度が45と極めて低い
- 視覚情報から必要なものを探す、見比べて書く作業に時間がかかる
- 全般的な理解がゆっくり

---

# Aさんへの支援提案

## 具体的な支援方法

### 学習環境の調整

- 十分な時間の確保
- 課題量の調整
- 視覚的に整理された教材
- 一度に提示する情報量を減らす

### 本人の強みを活かす

- 丁寧さ・正確さを評価
- 急がせない環境づくり
- スモールステップでの達成感

# Bさんの特性解説

## 認知特性の理解

### 強み

- 視空間が115と平均の上
- 視覚的な情報処理が得意
- 処理速度は100と平均

### 弱み

- ワーキングメモリー66、流動性推理78が低い
- 新しい課題への対応力・応用力に課題
- 記憶することの苦手さ
