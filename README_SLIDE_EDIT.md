# スライド編集機能 - 使い方ガイド

## 概要

このプロジェクトでは、GitHub Issue から直接スライドを選択して編集できる機能を実装しました。

### 主な機能

1. **プレゼンテーション選択**: Issue フォームから10個のプレゼンテーションから選択可能
2. **AI による自動編集**: Claude AI が指示に従ってスライドを自動編集
3. **スライドプレビュー**: 編集後のスライドが Issue コメントに直接表示される
4. **自動変換**: Markdown → HTML/PDF への自動変換

## 使い方

### 1. Issue を作成してスライドを編集

1. GitHub リポジトリの「Issues」タブを開く
2. 「New Issue」をクリック
3. 「スライド修正 #」テンプレートを選択
4. 以下を入力：
   - **編集するプレゼンテーション**: ドロップダウンから選択
     - ①すごいぞAI_AI概論
     - ②AIを使って画像生成をしてみよう
     - ③バナー作り
     - ④ディープリサーチ
     - ⑤スプレッドシート作成
     - ⑥資料作り
     - ⑦ホームページ作り
     - ⑧プレゼンとは
     - ⑨スライド作成
     - ⑩AIを活用した資料を使ってプレゼン
   - **修正内容**: 具体的な修正指示を入力

5. 「Submit new issue」をクリック

### 2. GitHub Actions が自動実行

Issue を作成すると、GitHub Actions が自動的に以下を実行します：

1. 選択したプレゼンテーションの Markdown ファイルを取得
2. Claude AI が指示に従ってスライドを編集
3. Marp で HTML/PDF に変換
4. スライド画像（PNG）を生成
5. すべてのファイルをリポジトリにコミット

### 3. 結果を確認

編集が完了すると、Issue に以下が表示されます：

- **スライドプレビュー**: 最初の5枚のスライドがアコーディオン形式で表示
- **ダウンロードリンク**: HTML/PDF のダウンロードリンク
- **ギャラリーリンク**: オンラインプレゼンテーションギャラリーへのリンク

## 編集例

### 例1: タイトルを修正
```
スライドのタイトルをもっとキャッチーに修正して
```

### 例2: 内容を追加
```
2枚目のスライドに、AIの活用事例を3つ追加してください
```

### 例3: トーン変更
```
全体のトーンをよりカジュアルで親しみやすい表現に変更してください
```

## ローカルでの変換（オプション）

ローカル環境でスライドを変換したい場合は、以下の手順でMarp CLIをインストールしてください：

```bash
# Node.js がインストールされている前提
npm install -g @marp-team/marp-cli

# すべてのプレゼンテーションを変換
bash scripts/convert_all_presentations.sh
```

## トラブルシューティング

### Issue を作成しても GitHub Actions が実行されない

- Issue に `presentation-edit` ラベルが自動的に付与されているか確認してください
- GitHub Actions のワークフローファイル (`.github/workflows/claude_bot.yml`) が正しくコミットされているか確認してください

### スライドプレビューが表示されない

- GitHub Actions のログを確認して、画像生成が成功しているか確認してください
- 画像ファイルが `presentations/[プレゼンテーション名]/slide-*.png` に生成されているか確認してください

### 編集が反映されない

- Issue の修正内容が明確に記述されているか確認してください
- GitHub Actions のログでエラーが発生していないか確認してください

## 技術詳細

### 使用技術

- **GitHub Actions**: 自動化ワークフロー
- **Claude AI (Anthropic)**: スライド編集
- **Marp**: Markdown → HTML/PDF 変換
- **Python**: スクリプト処理

### ワークフローファイル

- `.github/workflows/claude_bot.yml`: メインワークフロー
- `.github/ISSUE_TEMPLATE/edit-presentation.yml`: Issue テンプレート

### スクリプト

- `scripts/convert_all_presentations.sh`: 一括変換スクリプト
- `scripts/generate_index.py`: プレゼンテーション一覧生成
