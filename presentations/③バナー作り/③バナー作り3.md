## テクニック2：ブランドキット

### 統一感のあるデザイン

### 設定内容
- ブランドカラー（3色）
- ブランドフォント（2種類）
- ロゴ

### Geminiに相談
```
以下のブランドのカラーパレットと
フォントを提案してください。

ブランド：[名前]
業種：[業種]
イメージ：[イメージ]
```

## テクニック3：複数サイズを一括作成

### Canvaの機能
1. デザインを作成
2. 「サイズ変更」をクリック
3. 別のサイズを選択
4. 自動で調整

### 便利な使い方
Instagram → Twitter → Facebook
と一度に複数サイズ作成

## テクニック4：A/Bテスト用バリエーション

### Geminiに依頼
```
同じ内容で、異なるデザインアプローチの
バナーを3パターン提案してください。

内容：[バナーの内容]

1. 文字中心
2. 画像中心
3. ミニマル

それぞれの特徴とターゲット層への
訴求力を説明してください。
```
