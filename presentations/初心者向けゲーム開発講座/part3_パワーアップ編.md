# ゲームをもっと面白くしよう！

基本のゲームが完成したら
Geminiに追加機能をお願いしてみよう

**やりたいものを選んでチャレンジ！**

---

# 追加ミッション①：障害物を追加

## Geminiへのプロンプト

```
このゲームに障害物を追加してください。

- 赤い四角形の障害物を2つ配置
- 障害物に触れたらスタート位置に戻る
- 障害物はジャンプで避けられる高さにする
```

**難易度アップでもっと楽しく！**

---

# 追加ミッション②：背景を追加

## Geminiへのプロンプト

```
このゲームに背景を追加してください。

- 空は水色のグラデーション
- 地面は緑色の草原風
- 背景に雲を2〜3個描く
```

**見た目がきれいになる！**

---

# 追加ミッション③：ゴール画像を作る

## Geminiへのプロンプト（画像生成用）

```
ゲーム用の旗の画像を作ってください。

- チェッカーフラッグ模様
- 背景は白一色
- シンプルなデザイン
```

ダウンロードして「**goal.png**」として
imagesフォルダに保存

---

# 追加ミッション③：ゴール画像を使う

## Geminiへのプロンプト（コード修正用）

```
ゴールの見た目を画像に変更してください。
画像は images/goal.png を使います。
```

**オリジナルゴールの完成！**

---

# 追加ミッション④：タイマーを追加

## Geminiへのプロンプト

```
このゲームにタイマーを追加してください。

- 画面左上に経過時間を表示
- ゴールしたら時間を止める
- 「クリアタイム：○○秒」と表示する
```

**タイムアタックができる！**

---

# 追加ミッション⑤：コイン集め

## Geminiへのプロンプト

```
このゲームにコインを追加してください。

- 黄色い丸のコインを5個配置
- コインに触れると消えて点数が増える
- 画面右上にスコアを表示する
```

**点数を競えるようになる！**

---
