# AIエージェントとは？

## 役割を持ったAIの分業システム

- 1つのAIに全部やらせると品質が下がる
- **役割を分ける**ことで精度が上がる
- 人間のチームと同じ発想

## 今日作るエージェント

1. リサーチャー（調査役）
2. ライター（執筆役）
3. イメージジェネレーター（画像生成役）
4. パブリッシャー（投稿役）

---

# エージェント①：リサーチャー

## 役割：トレンド調査と情報収集

**このエージェントがやること**

- 今日のトピックに関する最新情報を調査
- 記事に使える事実やデータを収集
- ライターが使いやすい形で情報を整理

**使用するAPI**

- Gemini API（Google AI Studio経由で取得）

---

# リサーチャーのプロンプト

## そのまま使えるプロンプト

```
あなたは優秀なリサーチャーです。
以下のトピックについて、ブログ記事を書くための情報を調査してください。

【トピック】
{topic}

【調査してほしい内容】
1. このトピックの最新トレンドや動向
2. 読者が知りたい具体的な事実やデータ
3. 初心者にもわかりやすい説明のポイント
4. 記事に含めるべき重要なキーワード5つ

【出力形式】
JSON形式で以下の構造で出力してください：
{
  "trends": ["トレンド1", "トレンド2"],
  "facts": ["事実1", "事実2", "事実3"],
  "keywords": ["キーワード1", "キーワード2", "キーワード3", "キーワード4", "キーワード5"],
  "summary": "200文字程度の要約"
}
```

# エージェント②：ライター

## 役割：ブログ記事の執筆

**このエージェントがやること**

- リサーチャーの情報をもとに記事を執筆
- 読みやすく魅力的な文章を作成
- SEOを意識した構成

**ポイント**

- リサーチャーの出力を入力として受け取る
- 記事の構成（見出し）を先に決める

---

# ライターのプロンプト

## そのまま使えるプロンプト

```
あなたはプロのブログライターです。
以下の調査結果をもとに、noteに投稿するブログ記事を書いてください。

【調査結果】
{research_result}

【記事の要件】
- タイトル：読みたくなる魅力的なもの（30文字以内）
- 文字数：1500〜2000文字
- 構成：導入 → 本文3セクション → まとめ
- 各セクションに見出し（h2）をつける
- 初心者にもわかりやすい言葉で
- 具体例を必ず含める

【出力形式】
JSON形式で以下の構造で出力してください：
{
  "title": "記事タイトル",
  "sections": [
    {"heading": "見出し1", "content": "本文1"},
    {"heading": "見出し2", "content": "本文2"},
    {"heading": "見出し3", "content": "本文3"}
  ],
  "introduction": "導入文",
  "conclusion": "まとめ文"
}
```

# エージェント③：イメージジェネレーター

## 役割：アイキャッチ画像の生成

**このエージェントがやること**

- 記事の内容に合った画像を生成
- 各セクション用の挿入画像も作成
- noteに最適なサイズで出力

**使用するAPI**

- Gemini 2.0 Flash（画像生成対応モデル）
- Google AI Studio経由で同じAPIキーで使える

---

# 画像生成のプロンプト

## そのまま使えるプロンプト

```
以下のブログ記事のアイキャッチ画像を生成してください。

【記事タイトル】
{title}

【記事の内容】
{summary}

【画像の要件】
- スタイル：モダンでクリーンなイラスト調
- 色使い：明るく親しみやすい配色
- 構図：中央に主要なモチーフを配置
- テキストは含めない
- 16:9のアスペクト比

【イメージ】
テクノロジーや学習を連想させる、
前向きで明るい雰囲気の画像
```

# エージェント④：パブリッシャー

## 役割：noteへの投稿

**このエージェントがやること**

- 記事データをnoteのフォーマットに変換
- 画像をアップロード
- 記事を投稿（下書きまたは公開）

**使用するAPI**

- note API（記事投稿）
- 画像アップロードAPI

---

# パブリッシャーの処理フロー

## 投稿までの流れ

```
1. 画像をnoteにアップロード
   → 画像URLを取得

2. 記事本文にMarkdown形式で画像を埋め込み
   → ![](画像URL)

3. note APIで記事を投稿
   → タイトル、本文、ハッシュタグを送信

4. 投稿結果を確認
   → 成功したらURLを記録
```
