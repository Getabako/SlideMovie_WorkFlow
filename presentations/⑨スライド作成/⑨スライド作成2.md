```
【スライド3：現状の課題】について
内容を作成してください。

含めたいポイント：
- Webサイトが古い（5年前）
- スマホ対応していない
- アクセス数が減少（前年比-30%）
- 競合は最新デザイン

箇条書きで、簡潔に。
1スライド5行以内で。
```

## Googleスライドの基本操作

### 新規作成
1. Google Driveを開く
2. 「新規」→「Googleスライド」
3. テーマを選択

### スライド追加
- 左上の「+」ボタン
- または Ctrl + M（Windows）/ Cmd + M（Mac）

---

## レイアウトの選択

### 基本レイアウト
- **タイトルスライド**：表紙
- **タイトルと本文**：通常のスライド
- **タイトルのみ**：画像メイン
- **2列**：比較
- **空白**：自由レイアウト

## 配色の選定

### Geminiへの質問
```
以下のイメージに合う配色を
3パターン提案してください。

イメージ：
・信頼感
・プロフェッショナル
・明るく前向き

各色のカラーコード（#XXXXXX）も
教えてください。
```
