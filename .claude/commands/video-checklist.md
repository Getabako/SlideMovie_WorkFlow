# 動画作成チェックリスト

動画を作成する際は、以下の全ての要件を必ず同時に満たすこと。一つでも欠けている場合は動画として不完全。

## 必須要件

### 1. スライドの表示
- [ ] プレゼンテーションのスライド画像が正しく表示されている
- [ ] スライドは元のKeynote/PowerPointからエクスポートした正しい画像を使用
- [ ] `remotion-project/public/slides/slide_XX.png` に正しいスライドがコピーされている
- [ ] `slides_metadata.json` のスライド数が正確

### 2. 画像の表示
- [ ] スライド内の画像が正しく表示されている
- [ ] 抽象的なAI生成画像ではなく、正しいイラスト・写真が使用されている

### 3. 適切な画像の生成
- [ ] スライドに含まれる画像は元のプレゼンテーションの画像を使用
- [ ] 勝手にAI画像を生成して置き換えない

### 4. キャラクターの表示
- [ ] 画面右下にキャラクター（ナレーター）が表示されている
- [ ] キャラクター画像が読み込まれている

### 5. キャラクターのアニメーション
- [ ] キャラクターが適切にアニメーションしている
- [ ] 静止画ではなく動きがある

### 6. Talk/Idleアニメーションの切り替え
- [ ] 喋っている時は「talk」アニメーション
- [ ] 喋っていない時は「idle」アニメーション
- [ ] 音声タイミングと同期している

### 7. 音声
- [ ] VOICEPEAK "Japanese Female 1" を使用
- [ ] 速度は150（または指定された速度）
- [ ] 全スライドの音声が生成されている

### 8. 喋りのテンポ
- [ ] 間延びしていない
- [ ] 速すぎず、聞き取りやすいテンポ
- [ ] speed 150 が基本設定

### 9. 字幕の表示
- [ ] スクリプトの内容が字幕として表示されている
- [ ] 音声と同期している
- [ ] 読みやすいフォントサイズと位置

### 10. 背景画像
- [ ] `remotion-project/public/background.png` が最背面に画面いっぱいに表示されている
- [ ] 背景画像は全ての動画で共通使用

### 11. スライド背景色
- [ ] スライド背景色は空色ベースのグラデーション（紫ではない）
- [ ] グラデーション: `linear-gradient(135deg, #1e3a5f 0%, #2d4a6f 25%, #3d5a7f 50%, #4a6a8f 75%, #5a7a9f 100%)`

### 12. 表のスタイル
- [ ] 表の背景色は白
- [ ] 表のテキストは白以外（黒や濃い色）
- [ ] テキストが背景色と同化しないこと

## 動画作成前の確認手順

1. **スライド画像の確認**
   ```bash
   ls remotion-project/public/slides/
   # 正しいスライド画像があるか確認
   ```

2. **メタデータの確認**
   ```bash
   cat remotion-project/slides_metadata.json
   # スライド数が正確か確認
   ```

3. **音声ファイルの確認**
   ```bash
   ls presentations/[プレゼン名]/video_output/audio/
   # 全スライド分の音声があるか確認
   ```

4. **タイミングファイルの確認**
   ```bash
   cat remotion-project/public/timings.json | head -50
   # 字幕・キャラクタータイミングが設定されているか確認
   ```

## 動画作成後の確認手順

1. 動画の冒頭（0:00-0:30）を再生して確認
2. 動画の中盤を再生して確認
3. 動画の終盤を再生して確認

各確認で以下を目視チェック：
- スライドが正しいか
- キャラクターが表示されているか
- キャラクターが喋りに合わせて動いているか
- 字幕が表示されているか
- 音声が正しいか

## 技術仕様

- フレームレート: 30fps
- 解像度: 1920x1080
- チャンクサイズ: 3000フレーム
- 音声: VOICEPEAK Japanese Female 1, speed 150
- 出力形式: MP4
